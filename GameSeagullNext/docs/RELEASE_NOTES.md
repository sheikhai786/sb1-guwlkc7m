Experimental personal-device test build. No purchase or jailbreak required for compilation.

Download **GameSeagullNext-UNSIGNED.ipa**. This file must be signed with your Apple Account using a supported installer before iOS can run it. Downloading it in Safari alone does not install it. Preserve the ReplayKit broadcast extension when signing.

The package includes the app and its capture extension, both arm64. The accompanying manifest records the SHA-256 and package checks. Detection and physics tests run before compilation.

The intended live interface is a floating miniature pool table in Picture in Picture, not transparent lines drawn over the actual GamePigeon table. Live capture, background processing, signing and operation on iPhone 12 Pro / iOS 26.4.2 remain unverified until a physical-device test.

See `GameSeagullNext/docs/INSTALLATION.md` in the repository for the current setup and first-run instructions. No Apple credentials or signing certificates are bundled or requested in chat.
